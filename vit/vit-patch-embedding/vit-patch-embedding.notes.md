Ký hiệu

- H: Height - Chiều cao của ảnh
- W: Width - Chiều rộng của ảnh
- P: Patch Size - Kích thước cạnh của mỗi Patch, giả sử Patch hình vuông
- N: Number of Patches - Tổng số Patch được chia từ ảnh
- C: Number of channels - Số kênh màu của ảnh, thường là 3 với ảnh RGB



Ví dụ (B,H,W,C)=(1,4,4,3)
